# 學習足跡｜小四教師成果中心

獨立教師成果網站，以瀏覽器直接呼叫各原網站既有的教師登入與唯讀報表。未建立新資料庫、資料庫查詢API或身分系統，未搬移或改寫學習紀錄。

正式入口：https://wongngaiyam3-rgb.github.io/learning-resource-hub/teacher-results/

首次使用：輸入原四域食物鏈筆記的教師密碼；在「網站與資料來源」分別以原密碼連接七巧板、生態島、乘除法、熊貓、數卡、糖果或小科服務。短期憑證僅在頁面記憶體，重新整理需重接。密碼不保存。

功能：75位學生名冊，班號／科目／課題／網站／日期篩選，個別成果、作品證據、小組隔離、CSV及兩分鐘自動更新。

來源限制：各原服務只提供既有保留期及API回傳範圍。七巧板教師API只回傳完成與更新時間，不可補造提示、操作或用時。未統一雲端來源的網站列出原入口；沒有數據不當零分。現有接入來源是教學活動，獨立掌握程度待另建評估；不產生虛構能力百分比。

測試：node --test tests/model.test.mjs

資料保護：發布內容只有程式碼，不含學生資料、教師密碼或服務金鑰；報表由既有教師權限驗證。未發布新彙整後端。
